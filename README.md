# Defect Detection in Manufacturing using YOLO

This project uses Deep Learning and YOLO for automatic detection of defects in manufacturing images.

The model identifies and localizes defects in images using object detection.

The project includes data preparation, model training, validation, and defect detection.

YOLO is used to achieve fast and accurate real-time defect detection.
